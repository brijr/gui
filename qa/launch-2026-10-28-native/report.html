Coverage boundaries

  • These are local source fixes. Nothing was committed, deployed or released. Account-service changes require human review before landing under AGENTS.md.
  • Five native personas used isolated ordinary development profiles (GUI_ACCOUNT_REQUIRED=0) and the real Claude Code provider account already available on this Mac. Their edits changed real scratch-project files. No ACP stand-ins were used for persona proof.
  • Production account-required sign-in, fresh provider authentication, native installation from the downloaded DMG, and every external provider remain unproven. Gui sign-in accepts legal terms and awaits the user’s explicit approval; it was not clicked by QA.
  • The actual website was exercised in real browser tabs. The native editor is a Mac application, whose minimum window is not a 375px phone. Mobile website coverage used 375px and a 400kbit/s + 400ms server throttle. Native mobile preview used the built-in 390px preset and a slow scratch server; exact 375px native tool use was agent-reported, not independently verified.
  • Counts are distinct personas who reported a problem, not independent human participants or a statistical sample. All one-person ties are ordered by severity.
  • Harness-only issues (temporary app path capture, renamed Electron executable behavior, keyboard focus routing, localhost IPv6 collision and timing contention) are excluded from product defect counts. The proposed automated chat-focus test was removed because it did not faithfully reproduce native interaction; its unsuccessful attempts are not presented as passing coverage.
