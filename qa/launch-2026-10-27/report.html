Limits and decisions

  • Gui browser demo success is established. Live WorkOS signup, agent login, native install and a real AI edit are not verified by the persona runs.
  • Mobile used a real 375px browser with a server-side 3G approximation. Browser UA remained desktop; the proxy forwarded iPhone UA to the Worker. Physical touch, a virtual keyboard, and radio behavior were not exercised.
  • This is a local patch; no deployment or commit was made. Price for native usage remains a product-owner decision.
  • Initial Astro download404, localhost IPv6 collision, local HTTPS/HSTS mismatch, and throttle-server cancellation outage were excluded from product counts.
  • The parallel website performance run was oversubscribed; a serial rerun passed all23 tests at opening/closing p95 16.7ms. Two assertions were updated for intended #demo history and existing custom-scrollbar class.

Repeat the checks

Build the website with bun run --cwd www build, then run bun qa/launch-2026-10-27/harness.ts. The harness binds IPv4 127.0.0.1:4331 and 4332, uses the actual website Worker, local static assets and a memory-only database, and serves the existing alpha.7 DMG. Port 4332 adds the mobile server throttle. Use the explicit IPv4 address.
