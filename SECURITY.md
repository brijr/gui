# Security

Please report security issues privately, through [GitHub's private vulnerability reporting](https://github.com/brijr/gui/security/advisories/new), not in a public issue.

Include what you found, how to reproduce it, and what it affects (the app, the website at `www/`, or the account service at `accounts/`). You'll get a reply within a few days.

The README's **Security model** section describes what Gui trusts and what it doesn't.
